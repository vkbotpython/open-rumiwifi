Отдельно проверена страница входа `/cgi-bin/luci/web`: 130 текстовых строк, 0 китайских остатков.

Дополнительно проверены динамические узлы (MutationObserver): добавленный в DOM текст
и атрибуты `placeholder` / `title` переводятся без перезагрузки страницы.

## Что не переводится намеренно

- содержимое `<script>`, `<style>`, `<textarea>`, `<code>`, `<pre>`;
- пользовательские данные (имена сетей, устройств, введённые значения);
- два артефакта, попавших в обход HTML как «текст», но не являющихся интерфейсом:
  jQuery-селектор `option:contains('自动')` и JS-конкатенация `MAX_ROUTER_POLICY_LIST_NUM`.

## Словарь

- `extension/lang/zh_ru.json` — 1105 пар «китайская строка → русская».
- Словарь собран с нуля по живому интерфейсу; машинные переводы RUMIWIFI не используются.
- Ключи отсортированы по убыванию длины, а скрипт ищет самое длинное совпадение,
  поэтому короткие слова больше не «съедают» части длинных фраз.
