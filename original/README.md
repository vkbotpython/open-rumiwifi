# Разбор оригинального RUMIWIFI 1.11.8

В этой папке — только собственные скрипты и результаты анализа. Файлы самого
расширения в репозитории **не публикуются**: их можно скачать и распаковать
локально (оба артефакта в `.gitignore`).

```
download.js   — скачивает CRX из Chrome Web Store в original/rumiwifi.crx
unpack.py     — распаковывает CRX3 в original/extracted/
README.md     — этот разбор
```

Воспроизвести:

```bash
node original/download.js
python original/unpack.py
```

## 1. Скачивание и распаковка

CRX скачивается с официального сервиса обновлений Chrome:

```
https://clients2.google.com/service/update2/crx?response=redirect&prodversion=131.0
  &acceptformat=crx2,crx3&x=id%3Dmbiehbednoakmhlmjcpgpciocekdjabp%26uc
```

Магазин: `mbiehbednoakmhlmjcpgpciocekdjabp` (RUMIWIFI, версия 1.11.8, 341 652 байта).

Формат CRX3: сигнатура `Cr24`, версия 3, длина protobuf-заголовка 1309 байт,
ZIP начинается со смещения 1321. Никакого шифрования в контейнере нет —
ZIP открывается обычным архиватором.

## 2. «Шифрование»

Его нет. Единственная защита — минификация `js/content.js` (6,5 КБ в одну строку).
Словари `lang/zh_ru.json` (127 КБ) и `lang/zh_en.json` (62 КБ) — обычный JSON вида
`{"китайская строка": "русская строка"}`. Для чтения минифицированного кода
достаточно `npx js-beautify extracted/js/content.js`.

## 3. Как переводил оригинал

1. Контент-скрипт выполнялся на всех сайтах, но срабатывал только на локальных
   адресах (`10.*`, `100.*`, `172.*`, `192.*`, `miwifi.com`) и по признакам панели Xiaomi.
2. Загружал `lang/zh_ru.json` через `$.getJSON`.
3. Обходил текстовые узлы `body *:not(script):not(:empty)` и для каждой строки
   выполнял `text.replace(key, value)` **по всем ключам словаря в порядке их
   следования в JSON**.
4. На `DOMNodeInserted` запускал повторный проход через 50 мс.

Именно пошаговый `replace` в произвольном порядке — причина «каши» на новой панели:
короткие ключи вроде `日 → «дн.»` или `设备 → «устр.»` срабатывали раньше длинных
фраз и разрезали их на куски. Например, `下载米家APP` превращалось в
`Скачивание米ДомAPP`, а `星期日` — в `星期 дн.`.

## 4. Что ещё делал оригинал (и чего нет в open-версии)

| Возможность | Реализация | В open-версии |
|---|---|---|
| Тёмная тема | `css/themeDark.css`, только при активном Pro | убрано |
| Pro-подписка | флаг `extensionPay` с boosty.to | убрано |
| Рекламная карусель роутеров | `inc/routers.html` + owl.carousel | убрано |
| Ссылки Boosty / 4PDA в подвале | подмена элементов `#ft` | убрано |
| «Напоминание об обновлении» | через 11 дней перехват клика и `window.open('//updiap.com/...')` | убрано |
| Подмена placeholder пароля | `chrome.i18n` | оставлено штатными средствами словаря |

Переход на `updiap.com` зашит обфусцированно: массив
`["upd","firm","xpr","thug","lie","san",…]`, из него выбирается самая длинная
строка (`updiap`), к ней добавляется `.com`.

## 5. Выводы для новой версии

- Словарь — обычный JSON, его можно править и пересобирать без «дешифровки».
- Механизм замены нужно менять: сопоставление должно быть по самому длинному ключу,
  а не по порядку в файле.
- Рекламу, paywall и внешние редиректы в open-версии держать не нужно.
- Тексты новой панели (прошивка 2.0.28) заметно отличаются от словаря 2021 года,
  поэтому словарь собран заново по живому интерфейсу — см. `docs/coverage.md`.

## 6. Правовой статус

Файлы RUMIWIFI принадлежат его авторам и здесь не распространяются.
Разбор описывает поведение и архитектуру в исследовательских целях.
Иконки open-версии нарисованы заново, словарь переведён участниками проекта.
