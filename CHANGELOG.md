# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [2.1.5] — 2026-10-25

Переводится заголовок вкладки браузера.

### Добавлено

- `content.js` переводит `document.title`: вместо «小米路由器» вкладка
  называется «Xiaomi роутер», вместо «Redmi路由器» — «Redmi роутер».
- Заголовок переводится и при последующей смене из JS: `MutationObserver`
  и повторный проход `translateTitle()`.

### Исправлено

- Тесты проверяют отсутствие китайских символов в заголовке вкладки на всех
  страницах, а также динамическую смену заголовка.

## [2.1.4] — 2026-10-25

Исправлена кнопка добавления правила на странице переадресации портов.

### Исправлено

- «添加规则» на странице NAT переводится целиком — «Добавить правило»,
  без оставшегося китайского «规则».

## [2.1.3] — 2026-10-25

Исправлено наложение подписи «Режим» на текст выпадающего списка WAN.

### Исправлено

- На странице «Интернет» подпись «Режим» была абсолютно спозиционирована
  поверх правого края списка и при длинной русской подписи накладывалась
  на «Автоопределение WAN/LAN (рекомендуется)». Теперь она вынесена за
  правый край поля и не пересекается с текстом.

## [2.1.2] — 2026-10-25

Исправлены неполные переводы и выход русских подписей за края кнопок.

### Исправлено

- Интернет: подпись «智能识别网口“1”作为WAN口» переводится целиком —
  «Порт „1“ автоматически определён как WAN».
- Система: «当前版本» больше не остаётся на китайском; строка целиком читается
  как «Текущая версия 2.0.28, У вас последняя версия, обновление не требуется.».
- Чёрный список: пустые состояния «还没有设备添加进来», «还没有设备连接进来»
  и «无可添加设备» переведены, а не собираются из китайского текста и
  случайно найденного слова «Добавить». Также переводится заголовок «设备列表».
- DDNS: пустое состояние «还没有服务添加进来» переведено.
- Кнопки `.btn-m` больше не обрезают длинные подписи: «Добавить из списка
  онлайн» расширяет кнопку, а не выходит за её край (`extension/panel.css`).
- Выпадающий список режима WAN растягивается под «Автоопределение WAN/LAN
  (рекомендуется)», а подпись «Режим» вынесена за его правый край и больше
  не наезжает на текст.
- Заголовок «Сброс к заводским настройкам» больше не обрезается до «Сброс к»
  из-за фиксированной ширины 160 px.
- `tools/build_lang.py` теперь обновляет и `extension/lang/zh_ru.json`, а не
  только промежуточный `build/lang/zh_ru.json`.
- Добавлены регрессионные проверки динамических строк в `test-env/run-all.js`.

## [2.1.0] — 2026-10-25

Поддержка Firefox и сборка готовых пакетов.

### Добавлено

- Сборка `tools/build.py`: `dist/open-rumiwifi-<версия>-chromium.zip`,
  `...-firefox.zip`, `...-firefox.xpi` и `SHA256SUMS.txt`.
- Firefox-манифест с `browser_specific_settings.gecko` (id, минимальная версия 142,
  `data_collection_permissions: none`).
- `extension/api.js` — единая обёртка над `chrome.*` и `browser.*`.
- Тесты прогоняются в двух режимах: Chromium (`chrome.*`) и Firefox (`browser.*`),
  включая popup.
- CI собирает пакеты и публикует их как артефакты (GitHub Actions и GitLab CI).

### Изменено

- GitHub Actions обновлены до версий на Node.js 24:
  `checkout@v5`, `setup-python@v6`, `setup-node@v5`, `upload-artifact@v6`.
- CI использует Node.js 24; GitLab-образ `node:24-bookworm-slim`.
- README: отдельные инструкции для Chromium и Firefox.

## [2.0.0] — 2026-10-25

Первая публичная версия Open RUMIWIFI.

### Добавлено

- Собственный словарь на 1105 строк, собранный по интерфейсу прошивки Xiaomi 2.0.28.
- Покрытие 14 разделов панели и страницы входа: 1193 строки, 0 китайских остатков.
- Перевод `placeholder`, `title`, `alt` и кнопок `input[type=button]`.
- Конвертация дат `2025年10月25日` → `25.10.2025` и времени `14时05分` → `14:05`.
- `MutationObserver` для динамически добавляемых узлов.
- Popup: включение/выключение, выбор языка, переход в панель.
- CI для GitHub Actions и GitLab CI, `tools/verify.py`, jsdom-тесты на снимках панели.
- Иконки, нарисованные специально для проекта (`tools/make_icons.py`).

### Изменено

- Движок перевода переписан без jQuery: trie + поиск самого длинного совпадения.
- Словарь больше не зависит от старого `zh_ru.json` RUMIWIFI: машинные переводы
  не используются.
- Страница входа и служебные сообщения переведены заново.

### Удалено

- Рекламная карусель роутеров, ссылки Boosty/4PDA и paywall.
- Скрытый переход на `updiap.com` через 11 дней.
- Тёмная тема RUMIWIFI (требовала Pro-подписку).

### Безопасность

- Из снимков панели удалены session-токены и MAC-адреса.
- Скрипты сбора строк берут пароль только из `RUMIWIFI_PASSWORD`.
- Расширение не делает сетевых запросов и не вызывает API роутера.

### Лицензия

- Проект распространяется под **GNU GPL v3.0** (`GPL-3.0-only`).
