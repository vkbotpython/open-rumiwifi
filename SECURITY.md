# Безопасность

## Что делает расширение

- Загружает локальный словарь `lang/zh_ru.json` из собственного пакета.
- Заменяет текст в DOM открытой страницы панели роутера.
- Хранит в `chrome.storage.local` только настройки: включён перевод, язык,
  адрес панели (если задан вручную).

## Чего расширение не делает

- Не ходит в сеть: нет `fetch`/`XMLHttpRequest` к внешним адресам.
- Не вызывает API роутера (`/cgi-bin/luci/api/...`), не делает POST-запросов.
- Не читает, не сохраняет и не передаёт пароль роутера.
- Не содержит рекламы, аналитики, paywall и внешних редиректов.
- Не запрашивает `cookies`, `webRequest`, `history` и другие чувствительные права.

## Данные в репозитории

Снимки панели в `router/pages/` обезличены: session-токены заменены нулями,
MAC-адреса — на `AA:BB:CC:DD:EE:FF`. Пароли и имена устройств в репозиторий
не попадают. Скрипты `tools/crawl.py` и `tools/fetch_pages.py` берут пароль
только из переменной окружения `RUMIWIFI_PASSWORD` и не сохраняют его.

## Сообщить об уязвимости

Если вы нашли проблему безопасности, пожалуйста, **не открывайте публичный issue**.
Используйте приватный отчёт:

- GitHub: вкладка **Security → Advisories → Report a vulnerability**;
- GitLab: **Security & Compliance → Vulnerability Report** (или private issue).

Опишите шаги воспроизведения, версию браузера и ожидаемое поведение.
Мы постараемся ответить в течение недели.
