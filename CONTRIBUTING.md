# Как помочь проекту

Спасибо, что хотите помочь с переводом! Здесь всё устроено просто:
исходники перевода — JSON-файлы в `data/ru/`, из них собирается
`extension/lang/zh_ru.json`.

## Что понадобится

- Python 3.10+ (стандартная библиотека; для иконок — Pillow);
- Node.js 20+ (только для тестов, `jsdom`);
- браузер на Chromium (Chrome, Edge, Yandex) для ручной проверки.

## Быстрый старт

```bash
git clone <repo-url>
cd open-rumiwifi

python tools/build_lang.py      # собрать словарь и проверить покрытие
cd test-env
npm ci
node run-all.js                 # прогнать тесты на снимках панели
```

## Как добавить или исправить перевод

1. Найдите китайскую строку:
   - в снимке страницы: `router/pages/*.html`;
   - или в живой панели через DevTools → Elements.
2. Добавьте пару в подходящий файл `data/ru/*.json`, например:

   ```json
   "访客Wi-Fi": "Гостевой Wi-Fi"
   ```

3. Пересоберите словарь:

   ```bash
   python tools/build_lang.py
   ```

   Скрипт сам проверит, что на всех снимках и на странице входа
   не осталось китайских символов. Если что-то осталось — он покажет строки.
4. Прогоните тесты и обновите отчёт:

   ```bash
   python tools/report.py
   cd test-env && node run-all.js
   ```

## Правила перевода

| Китайский | Принятый перевод |
|---|---|
| 路由器 | роутер (не «маршрутизатор») |
| 小米路由器 | Xiaomi роутер |
| Wi-Fi / WiFi | Wi-Fi |
| 上传 | отдача (скорость отдачи) |
| 下载 | загрузка (скорость загрузки) |
| 带宽 | пропускная способность |
| 终端 / 设备 | устройство |
| 子路由 | сателлит (Mesh-сателлит) |
| 节点 | узел |
| 访客 | гостевой |
| 重启 | перезагрузить |
| 恢复出厂设置 | сброс к заводским настройкам |
| 保存 | сохранить |
| 应用 (кнопка) | применить |

Общие требования:

- никакого машинного перевода «как есть» — только осмысленный текст;
- единая терминология: если в словаре уже есть термин, используйте его;
- не переводите названия моделей (`AX3000T`, `BE7000`) и бренды;
- сохраняйте плейсхолдеры `{$0}`, `{$1}`, `{$time}` без изменений;
- не добавляйте HTML в значения: заменяется только текст.

## Снимки панели

`router/pages/` — обезличенные HTML-страницы для офлайн-тестов.
Если добавляете новую страницу:

- удалите session-токены (`;stok=...` → нули);
- замените MAC-адреса на `AA:BB:CC:DD:EE:FF`;
- убедитесь, что в файле нет паролей, SSID и других личных данных.

## Стиль кода

- `extension/content.js` — обычный ES2020, без сборщиков и зависимостей.
- Python-скрипты — стандартная библиотека, PEP 8, без лишних пакетов.
- Коммиты — в стиле [Conventional Commits](https://www.conventionalcommits.org/):
  `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`.

## Чек-лист перед PR

- [ ] `python tools/build_lang.py` завершается без ошибок;
- [ ] `python tools/verify.py` проходит;
- [ ] `cd test-env && node run-all.js` — все страницы зелёные;
- [ ] в снимках нет личных данных и живых токенов;
- [ ] обновлён `docs/coverage.md` (если менялся набор строк);
- [ ] описание PR объясняет, что и почему изменено.
